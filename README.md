# SolusiBelajar
a. Judul & Deskripsi: SolusiBelajar yang dibuat untuk menjadi solusi belajar bagi siswa di kehidupan sekolah sehari hari, tujuan pengunaan untuk dibuatnya SolusiBelajar ialah menciptakan platform untuk pembelajaran dan membantu memahami materi dimana saja lewat aplikasi dan mudah diakses bagi para pelajar kelas 10, 11, 12. 
b. Teknologi yang Digunakan: HTML5, CSS3, dan JavaScript (ES6). Tailwind CSS (melalui CDN) untuk desain antarmuka responsif dan modern. Lucide Icons (melalui CDN) untuk ikon visual antarmuka, Google Fonts (Poppins) untuk tipografi teks dan GitHub Pages.
c. Pemanfaatan AI (AI Usage Disclosure): ○ Gemini (Google AI). ○ "Buatkan saya rancangan website yang bertema solusi di kegiatan sehari hari dengan tema belajar dengan materi sekolah SMA, lengkap dengan kode HTML, CSS, dan JavaScript terpisah."  ○ Menyesuaikan daftar modul mata pelajaran agar mencakup materi kelas 10, 11, dan 12 dari kurikulum SMA (baik MIPA maupun IPS). Menambahkan fitur pencarian cepat (search bar) dan popup ringkasan interaktif agar siswa lebih mudah mencari materi spesifik.
d. Panduan Penggunaan: Buka situs web aktif SolusiBelajar melalui tautan GitHub Pages berikut: (https://ichasalwa21-hash.github.io/SolusiBelajar/)
Gunakan kolom pencarian di halaman utama untuk mencari materi pelajaran dengan cepat.
Klik tombol Filter Kelas (X, XI, XII) untuk menyaring materi sesuai tingkat sekolah.
Klik tombol "Lihat Ringkasan" pada kartu materi untuk membaca konsep, rumus, dan tips ujian secara instan.
Gunakan fitur Timer Pomodoro (tekan Mulai) untuk mengatur waktu fokus belajar dan Target Belajar untuk mencatat tugas harianmu.
